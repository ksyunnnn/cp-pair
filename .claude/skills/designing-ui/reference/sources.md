# 場面ごとの出典

HIG の URL は `https://developer.apple.com/design/human-interface-guidelines/<page>`。HIG に Web 向けのページはない。cp-pair は iPhone の Safari 向けなので、iOS の記述に合わせる。

| 場面 | 使う | 避ける | ページ |
|---|---|---|---|
| 1 件の詳細を重ねて出す | 半分の高さで止まるシート（medium detent）。広げたら不透明 | モーダルにして、後ろの画面を操作できなくする | sheets |
| オンとオフ | Switch | — | toggles |
| 入力 | 値をその場で検証する。キーボードが入力欄を隠さない | — | entering-data |
| 削除や取り消せない操作の確認 | 取り消せない操作だけ確かめる。ボタンは具体的な名前 | 戻せる操作への確認 | alerts、action-sheets |
| 主な操作 | 1 画面に 1 つ。色は主な操作の背景にだけ使う | 色付きの操作を増やす | buttons、color |
